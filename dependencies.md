# Abhängigkeiten

## Framework

- **Blazor WebAssembly** (`Microsoft.AspNetCore.Components.WebAssembly` 8.0.27)
  Führt die .NET 8-Anwendung vollständig im Browser aus (via WebAssembly). Kein Server notwendig.
  Lizenz: MIT · https://github.com/dotnet/aspnetcore

## NuGet-Pakete

- **Markdig** 1.2.0
  Konvertiert Markdown-Text in HTML, verwendet in Textblöcken mit Formatierungsunterstützung.
  Lizenz: BSD-2-Clause · https://github.com/xoofx/markdig

## JavaScript-Bibliotheken (CDN)

- **SortableJS** 1.15.0 (`cdn.jsdelivr.net`)
  Ermöglicht Drag & Drop zum Umsortieren von Layout-Blöcken.
  Lizenz: MIT · https://github.com/SortableJS/Sortable

## Web-Fonts (Google Fonts CDN)

- **Geist** (400–700) — UI-Schriftart
- **Geist Mono** (400–500) — Monospace-Schriftart für Code-Ausgaben
  Lizenz: SIL Open Font License 1.1 · https://github.com/vercel/geist-font

## Icons

- **Lucide** — UI-Icons und Grafiken sowohl für die App als auch den generierten HTML-Code
  Lizenz: ISC (Feather-Basis: MIT) · https://github.com/lucide-icons/lucide
